# Stage 3 controlled CPU dataset

This directory is authoritative machine-specific evidence generated by `scripts/run_cpu_benchmarks.py` from Git commit `a4c9eb1176c0ff2efede6ee110ecad75e5bc423f` on 2026-09-23.

- `raw_timings.csv`: 660 individual measured repetitions in actual execution order.
- `summary.csv`: 60 configuration summaries and deterministic bootstrap intervals.
- `environment.json`: protocol, timer scope, Git state, machine/toolchain snapshot, and telemetry availability.
- `affinity_probe.txt`: verbatim libgomp environment and affinity probe.

The output directory was intentionally untracked while the experiment ran, so `environment.json` records it as the only Git status entry. The benchmark code itself was the clean committed revision above. See `docs/MASTER_LEDGER.md` and `docs/benchmark_protocol.md` for interpretation and reproduction commands.
