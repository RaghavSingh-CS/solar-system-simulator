# Data provenance

No Solar System ephemeris is stored yet. A future JPL Horizons snapshot must include the raw query/response, retrieval timestamp, epoch, frame, center, time scale, and units.

Small, stage-specific benchmark datasets may be committed when they are authoritative experiment evidence and include the exact code revision, protocol, environment metadata, raw measurements, and generated summary. Disposable pilots, build artifacts, and large generated datasets remain uncommitted.
